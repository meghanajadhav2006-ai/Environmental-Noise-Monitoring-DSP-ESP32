# Environmental Noise Monitoring and Classification Using DSP and ESP32

## Overview

Environmental noise is a common concern in urban areas, workplaces, and residential environments. This project implements a hardware-based environmental noise monitoring and classification system using an ESP32 microcontroller and Digital Signal Processing (DSP) techniques.

The system captures sound signals through a sound sensor or microphone, processes the collected data, and uses the implemented classification method to identify noise categories. The project demonstrates the application of embedded systems and digital signal processing in environmental noise analysis.

## Objectives

- Monitor environmental sound using an ESP32-based hardware setup.
- Process sound signals using suitable DSP techniques.
- Analyze sound characteristics for noise classification.
- Demonstrate the integration of embedded hardware and signal processing.
- Explore the application of noise monitoring in environmental awareness.
